## 复现额外的视频预览检查

普通检查命令已包含 PNG 生成及预览验证。可以额外指定本地可读的视频文件：

```bash
DRAWER_CHECK_MOVIE='/absolute/path/to/test.mp4' zsh scripts/check-native.sh
```

该命令将视频用于本机缩略图检查，不上传视频。不要使用未下载的云文件或需要交互授权才能读取的路径。
